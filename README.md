## 🛠️ عن المنصة
**سحورنا 2027** هي منصة ويب تفاعلية حديثة تم بناؤها باستخدام **React 19** و **Vite** و **Tailwind CSS** لتكون الرفيق الرقمي للمسلم خلال شهر رمضان المبارك. تجمع المنصة بين دقة البيانات الدينية وجمال التصميم العصري (Cyber-Ramadan Luxury Gold Style) مع 17 خدمة وميزة شاملة.

---

## 👥 فريق العمل (المطورون)
تم بناء هذا العمل بجهد جماعي من فريق متميز:
* **كريم عمر**: المطور الأساسي والمصمم البصري (Full Stack Developer).
* **مصطفى محمد (عبقرينو)**: شريك التطوير والبرمجة.
* **محمد بركات**: تطوير وإدارة المحتوى.
* **يوسف عويس**: مراجعة البيانات والخدمات.
* **يوسف مصطفى**: تنسيق واجهة المستخدم.

---

## ✨ الخدمات والميزات الـ 17

### 🕋 الخدمات الدينية
* **مواقيت الصلاة**: عرض دقيق وتحديد للموقع عبر Aladhan API مع عداد للصلوات القادمة، وسلايدر لصور المساجد، ودليل سنن الوضوء.
* **المصحف الشريف**: تصفح وقراءة سور القرآن الكريم (114 سورة) مع الاستماع لأكثر من 20 قارئاً وتتبع آيات السورة.
* **متابعة الختمة**: خطة ذكية لتتبع ختم القرآن خلال 30 يوماً حسب الهدف (ختمة، ختمتان، ثلاث، إلخ) مع حساب النسب المئوية.
* **أذكار المسلم**: أكثر من 40 ذكراً مقسمة إلى أذكار الصباح، المساء، بعد الصلاة، والاستيقاظ مع عدادات تفاعلية.
* **المسبحة الإلكترونية**: وضعان (مسبحة خشب أبنوس مصرية تفاعلية + عداد رقمي LCD) مع إحصائيات التسبيح الكلي.
* **حاسبة الزكاة وفتاوى الصيام**: حاسبة لزكاة الفطر وزكاة المال والصدقات، مع 100 فتوى فقهية موثقة قابلة للبحث.
* **المكتبة الدينية**: قصص الأنبياء (8 قصص كاملة) مع قارئ نصوص قابل لتكبير الخط وتبديل النمط (ليلي/داكن/سيبيا).

### 🍕 جودة الحياة والترفيه
* **وصفات الفطور**: 50 وصفة رمضانية (25 طبق رئيسي مصري + 25 حلويات شرقية) مع إمكانية المشاركة عبر واتساب.
* **نصائح السحور**: 50 فكرة سحور صحية لمنع العطش والجوع مقسمة لـ 4 فئات مع عداد تنازلي للإمساك.
* **صحتك في رمضان**: 100 سلوك ونصيحة طبية عبر 6 فئات صحية مع محرك بحث فوري.
* **متبع العادات**: متتبع متقدم للعادات الحسنة والإقلاع عن العادات السيئة مع عداد ساعات الإنجاز.
* **أعمال الخير والإحسان**: 30 بطاقة تقليب تفاعلية للمهام الخيرية مع احتفال كونفيتي.
* **جدول المسلسلات**: متابعة 34 عملاً رمضانياً مع عداد الحلقات المشاهدة وفلاتر القنوات.
* **ركن الأطفال**: معلومات مبسطة ومسابقة تفاعلية لتشجيع الصغار على الصيام والتعلم.
* **فريق العمل**: صفحة استعراض للمطورين الخمسة مع السير الذاتية والاقتباسات وروابط التواصل.

## 🚀 التقنيات المستخدمة
* **Framework**: React 19 + TypeScript + Vite.
* **Styling**: Tailwind CSS v4 مع نظام ألوان متطور (Dark/Light Mode) ومؤثرات الفوانيس المتأرجحة.
* **APIs**: Aladhan API, Al-Quran Cloud API.
* **UX/UI**: FontAwesome 6, Lucide Icons, Canvas Confetti.
